# Dashboard สรุปการทำแบบทดสอบก่อนอบรม — Learning T-Map

หน้าเว็บสรุปผลแบบทดสอบก่อนอบรม โครงการพัฒนาบุคลากรด้านการสร้าง Learning T-Map ปักหมุดแหล่งเรียนรู้คู่ชุมชน

- ดึงข้อมูลสดจาก Google Sheets (ชีตการตอบกลับของ Google Forms) แบบเรียลไทม์
- รีเฟรชอัตโนมัติ ตั้งได้ 15 วินาที / 30 วินาที / 1 นาที / 5 นาที หรือปิด
- สรุป KPI, กราฟการกระจายคะแนน, ไทม์ไลน์การเข้าทำ, ผลรายข้อ, สรุปตามหน่วยงาน และตารางรายชื่อผู้เข้าร่วม
- ตั้งเฉลยเองได้ (ถ้าไม่ตั้ง ระบบจะวิเคราะห์เฉลยจากความสัมพันธ์ระหว่างตัวเลือกกับคะแนนรวม)
- ส่งออกผลเป็นไฟล์ CSV เปิดด้วย Excel ได้

ไฟล์เดียวจบที่ `index.html` ไม่ต้องติดตั้งอะไรเพิ่ม

## เปลี่ยนไปใช้ชีตอื่น
ต่อท้าย URL ด้วย `?sheet=<SHEET_ID>` หรือแก้ค่า `SHEET_ID` ในไฟล์ `index.html`
ชีตต้องตั้งค่าแชร์เป็น "ผู้ที่มีลิงก์" (ผู้อ่าน)

## เกมสุ่มรายชื่อ (`random.html`)
หน้าสุ่มรายชื่อผู้นำเสนองาน ดึงรายชื่อสดจากชีตเดียวกัน (ตัดชื่อซ้ำอัตโนมัติ)
- สุ่มครั้งละ 1/2/3/5 คน มีแอนิเมชันชื่อวิ่ง เสียงประกอบ และพลุกระดาษ
- ไม่สุ่มซ้ำคนเดิม (จำไว้ใน localStorage) กรองเฉพาะอำเภอได้ คลิกชื่อเพื่อพักไม่ให้ถูกสุ่ม
- โหมดเต็มจอสำหรับฉายโปรเจกเตอร์ กด Spacebar เพื่อสุ่ม กด F เต็มจอ
